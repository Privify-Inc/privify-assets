# Privify Assets

Static brand assets for Privify — logo artwork shared across the Privify repos and sites.
No code, no build step.

## Contents

- `privify_logo.png` — primary logo
- `privify_orig.png` — original/source logo artwork
- `privify_transparent.png` — logo with transparent background

## Usage

Reference these files directly from consuming repos (e.g. as a git submodule, or by copying
the file needed) rather than duplicating logo artwork elsewhere.
